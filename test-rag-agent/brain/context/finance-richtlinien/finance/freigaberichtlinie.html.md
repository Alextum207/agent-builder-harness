# Freigaberichtlinie Eingangsrechnungen

Erfundenes Testdokument der Muster Industrie GmbH.

## Freigabegrenzen

| Bruttobetrag              | Freigabe durch   |
|---------------------------|------------------|
| bis 5.000 EUR             | Teamleitung      |
| über 5.000 bis 25.000 EUR | Bereichsleitung  |
| über 25.000 EUR           | Geschäftsführung |

## Vier-Augen-Prinzip

Jede Zahlung wird von zwei Personen freigegeben. Wer eine Rechnung erfasst, darf sie nicht selbst freigeben.
